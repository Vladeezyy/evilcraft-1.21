EvilCraft (Unofficial Fabric Port)

Dark magic, blood and vengeful spirits. EvilCraft on Fabric for Minecraft 1.21.1, 1.21.11, 26.1.2, 26.2 and 26.3, with all of its content.

📜 Original mod

This is an unofficial port of EvilCraft by rubensworks (kroeser) and the CyclopsMC contributors (source) from NeoForge to Fabric. The original is open source under MIT (its README: code and images under Creative Commons Attribution 4.0); the JEI and Jade integrations come from its EvilCraft-Compat (MIT), which the original bundles into its jar. Source of this port: github.com/Vladeezyy/evilcraft-1.21, LGPL-3.0, with the licenses and credits of the original kept. All the content, art, texts and ideas are theirs; please report bugs of this port to this port's issues, not to the original authors.

How this port differs from the original

  • Fabric instead of NeoForge. Same content, recipes, loot and numbers. Based on EvilCraft 1.2.109 for 1.21.11 and 26.x, and on 1.2.99 for 1.21.1.
  • Fluids use Fabric's Transfer API: Dark Tanks, the Blood Infuser and the other blood machines connect to the pipes and tanks of other Fabric mods.
  • JEI and Jade (optional): the recipes of the Blood Infuser, the Environmental Accumulators, the Spirit Reanimator and the Spirit Furnace (its mob drops come from the server, which does not need JEI); Jade shows the contents of the Box of Eternal Closure and the parts of a broom.
  • Translations: English, Russian, Ukrainian, German, Spanish and Brazilian Portuguese are complete; the other translations of the original are kept.
  • Fixes over the original 1.21.1: blood put into tanks by the mod itself is saved with the chunk; villagers take the Werewolf profession; a hopper under a halted Spirit Furnace restarts it.
  • Tested: the GameTests of the original (104–106 per version) on every build, a client test scene (blocks, fluids, machines, mobs, the book, fluid transfer, JEI and Jade), the release jar on a dedicated server.

🩸 About the mod

EvilCraft brings dark magic to Minecraft: collect blood, harness the power of spirits and the weather, and fight the creatures of the night.

  • Blood: a fluid that drops from the mobs you kill, stored in Dark Tanks, Blood Chests and Entangled Chalices (linked over any distance), and used by most machines
  • Machines: the Blood Infuser, the Spirit Furnace, the Spirit Reanimator, the Environmental Accumulator (weather in a bottle), the Sanguinary Environmental Accumulator, the Purifier, the Colossal Blood Chest and more
  • Creatures: Werewolves, Vengeance Spirits (catch them in a Box of Eternal Closure), Poisonous Libelles, Netherfish, Controlled Zombies
  • Tools and items: brooms you build from parts, the Vengeance Ring, the Mace of Distortion, the Necromancer's Staff, the Kineticator, Weather Containers, Blood Extractors, Lightning Grenades, ...
  • The world: Dark Ore, undead trees, blood and poison, the Spirit Portal and the Gemstone of Doom
  • Origins of Darkness: the in-game book that explains it all

📦 Installation

Needed on both the client and the server. Download the file for your Minecraft version: a file for one version does not load on another.

  • 26.3: Fabric Loader 0.19.5+, Java 25, Fabric API 0.164.0+, Cyclops Core for Fabric 1.30.0-1212+, Forge Config API Port 26.3.1+
  • 26.2: Fabric Loader 0.19.5+, Java 25, Fabric API 0.161.0+, Cyclops Core for Fabric 1.30.0-1143+, Forge Config API Port 26.2.1+
  • 26.1.2: Fabric Loader 0.19.5+, Java 25, Fabric API 0.155.3+, Cyclops Core for Fabric 1.31.4+, Forge Config API Port 26.1.5+
  • 1.21.11: Fabric Loader 0.19.5+, Java 21, Fabric API 0.141.6+, Cyclops Core for Fabric 1.25.5+, Forge Config API Port 21.11.1+
  • 1.21.1: Fabric Loader 0.16.14+, Java 21, Fabric API 0.116.17+, Cyclops Core for Fabric 1.30.0+, Forge Config API Port 21.1.6+
  • Optional, on the client: JEI (with MezzConfig) and Jade

Settings: config/evilcraft-common.toml, config/evilcraft-client.toml.
